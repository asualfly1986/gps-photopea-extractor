ตั้งค่า Google Photos API Client ID

การดึงรูปภาพโดยตรงจาก Google Photos ต้องใช้ Google OAuth Client ID เพื่อเชื่อมต่อสิทธิ์กับ Google

ระบบจะบันทึก Client ID ไว้ในเบราว์เซอร์ของคุณอย่างปลอดภัย

วิธีสร้าง Client ID ฟรี (Google Cloud Console):

  1. ไปที่ Google Cloud Console แล้วสร้าง Project ใหม่
  2. ไปที่ APIs & Services > Credentials
  3. กด Create Credentials > OAuth client ID เลือกประเภท Web application
  4. ใส่ Origin ของคุณ (เช่น http://localhost หรือ URL เว็บ) ใน Authorized JavaScript origins
  5. คัดลอก Client ID ที่ได้มาวางในช่องด้านบน แล้วกดบันทึก
